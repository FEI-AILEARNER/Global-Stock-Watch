- 新建项目（Next.js 16、React 19、Tailwind CSS 4、TypeScript ~5.9.3），平台名称 Global Stock Watch。
- 用一次性脚本 `scripts/import/import_xlsx.py` 把原 Excel（表“监控清单”，A1:M53，更新于 2026-11-19）导入成 JSON：30 个标的、6 个板块、36 条新闻、表下方 15 段说明。原文逐字保留；原 Excel 没有进仓库。

- `npm run check` 通过：类型检查无错误；测试 19 项全部通过；构建成功（首页、日历、纪律、更新记录、30 个详情页静态生成，`/api/quotes` 动态）。
