# 估值相关信息：补什么、从哪里取、多久更新（2026-11-22）

Fei 的要求（2026-11-22 原话）：“想想还有哪些信息能补充，有利于判断各个股票的价值，包括招股书的研读等等。”

出发点是 Fei 自己的方法：买离现金流最近、最被验证的一环；用击球价和退出价做纪律；退出分复利机、周期股、期权型三种逻辑。所以要补的是**能直接回答“这家公司值多少钱、这个价格里押了什么”的、可以核对的数字**，而不是更多新闻。

总原则：

- 只用官方来源：SEC EDGAR 上的 10-K、10-Q、8-K（含财报新闻稿附件）、S-1／F-1／424B、DEF 14A、Form 4、20-F／40-F／6-K，以及公司投资者关系网站的财报新闻稿。
- 每个数字带：数值、单位、所属期间、来源（链接）、核对日期。没取到的写“本轮未检索到”和原因，不留空、不估。
- 算出来的东西（同比、近四季、自由现金流、估值倍数）只是算术：页面上写公式和输入。
- 不加判断：本轮不改击球价、退出价、态度；“什么情况下判断会变”只整理已有判断里写过的条件。

## 要补的信息

| 类别 | 为什么对估值有用 | 从哪份文件取 | 多久更新 |
| --- | --- | --- | --- |
| **财务快照**：营收、毛利、营业利润、净利润、稀释每股收益、经营现金流、资本开支、自由现金流、股权激励、折旧摊销；最近季度、近四季（TTM）、最近财年，带同比 | 现金流是 Fei 方法的核心。“扣除股权激励后的自由现金流”专门防止把用股票发的工资当成利润；资本开支和自由现金流能看出增长是不是靠烧钱买来的（SpaceX、Oklo、GOOGL 的资本开支问题） | 10-K、10-Q 的 XBRL 数据（脚本自动取）；财报新闻稿先于 10-Q 发布时，从新闻稿的表格人工录入；外国公司从 20-F／40-F 和 6-K 新闻稿录入 | 每次财报后；Fei 说“更新”时跑脚本 |
| **资产负债**：现金及短期投资、有息负债、净债务；债务到期 | 企业价值要用；净债务决定周期下行时能不能熬过去（IRDM 杠杆、VST 和 CEG 的负债、LEU 的可转债） | 资产负债表（同上）；到期表在 10-K／10-Q 的债务附注 | 每季 |
| **股本和稀释**：已发行股数（封面）、一年前的股数、近四季回购和发行、可转债和认股权证 | 每股价值 = 公司价值 ÷ 股数。小盘的核能、太空公司靠增发活着（OKLO、SMR、LUNR），股数一年涨多少直接摊薄每股价值 | 10-K／10-Q 封面；现金流量表；附注 | 每季 |
| **估值口径**：按现价、按记录价、按击球价各算一遍：市值、企业价值、市盈率、EV/EBITDA、市销率、自由现金流收益率、扣除股权激励后的自由现金流收益率 | 把“击球价”翻译成倍数，才能看出这个价格里假设了什么（例如 NVDA 击球价 $145 约等于近四季净利润的 15 倍） | 由上面的数字算出，页面写公式 | 现价每次打开页面；其余随财报 |
| **业务结构**：分部收入和利润、地区（如中国占比） | 看利润来自哪一环（Fei 的“离现金流最近的一环”）；看政策风险落在多大的收入上 | 财报新闻稿、10-K／10-Q 的分部附注 | 每季 |
| **在手订单、长约**：backlog、RPO、PPA | 订单是未来营收里“已经被验证”的部分；对 GEV、BWXT、LUNR、RKLB、CEG、VST 最直接 | 财报新闻稿、10-Q | 每季 |
| **客户集中度** | 一个大客户就能改变估值（台积电、美光、SK 海力士的 AI 客户；X-energy 的 Dow 和 Amazon） | 10-K 的 Risk Factors 和收入附注、招股书 | 每年；有重大变化时 |
| **公司指引**：下一季或全年，和上一次比是上调、下调还是维持 | 管理层自己给的方向，是检验投资逻辑最快的数字 | 财报新闻稿 | 每季 |
| **治理和利益一致性**：管理层和大股东持股、双层股权、近期内部人买卖 | 双层股权（GOOGL、COIN、XE、SpaceX）决定小股东有没有话语权；NVDA 正在经历的治理事件本身就是折价理由 | DEF 14A（持股表）、10-K 封面、Form 4 | 每年（委托书）；Form 4 随时 |
| **风险因素**：公司自己承认的、与这家公司特别相关的三到五条 | 公司在法律文件里写的风险比新闻稿诚实；只挑非套话的 | 10-K／20-F 的 Risk Factors、10-Q 的更新、招股书 | 每年；有新增时 |
| **招股书研读**（上市不满约三年、历史财报短的标的） | 上市前的财务、股权结构、锁定期和关联交易只在招股书里；锁定期到期是可以预见的供给 | S-1／F-1／424B4、Form 10 | 上市时读一次；锁定期、关联交易有变化时补 |
| **什么情况下判断会变** | 把定价依据里已经写过的关键条件，整理成两三条能对着数字检查的指标，下次财报出来直接对照 | 已有的投资逻辑（`rationale`）＋最新的数字 | 每次更新 |

需要读招股书的标的（本清单里上市不满约三年）：**SKHY**（2026-07 美国上市，F-1／424B4）、**SPCX**（2026-06 上市，S-1／424B4）、**XE**（2026-04 上市，S-1／424B4）。其余：OKLO（2024 年 SPAC 合并）、GEV（2024 年分拆，Form 10）、LUNR、DNA、RKLB（SPAC）上市都超过两年、已有完整的 10-K，本轮不读招股书，用 10-K。

## 不补的信息

| 不补 | 理由 |
| --- | --- |
| 卖方目标价、评级、一致预期 | 不是公司官方文件；平台上已有的一致预期沿用旧笔记口径并注明未重新核实 |
| 媒体转述的财务数字（官方原文可取时） | 以官方为准；只在官方原文打不开时才作为新闻记录，并标“媒体” |
| 需要付费数据的指标：做空比例、机构持仓变化、期权隐含波动率、Beta | 没有官方免费来源，也不处理密钥 |
| 自己做的 DCF 或“内在价值” | 那是判断，不是事实；本轮只做算术口径 |
| 汇率换算后的美元口径（台积电、SK 海力士、Cameco） | 汇率没有当天的官方来源；非美元公司只列原币数字，需要股价的倍数不算（公司自己给了美元口径的除外） |
| 传闻、社交媒体、未核实的“知情人士” | 无法核实 |
| 13F 机构持仓 | 滞后一个季度，对单个公司的估值意义小 |

## 取数的方法和已知的局限

- **自动取数**：`scripts/fundamentals/sec-xbrl.ts` 从 SEC 的 XBRL 接口（`data.sec.gov`，公司随 10-K／10-Q 提交的结构化数据）取最近一份年报和季报的数字。各公司用的标签不同（营收、债务尤其多样），脚本按顺序找、可以在每个文件的 `xbrl` 里指定；输出的每个数字都记下用的标签。现金流量表在 10-Q 里只有年初至今，单季由两期相减（页面标 *）。
- **新闻稿先于 10-Q**：NVDA、AMAT 的最新一季只有新闻稿（8-K），CEG 的 10-Q 已提交但数字还没进 XBRL 接口——这几家的最近一季是人工从新闻稿录入的（`manual: true`，脚本重跑不覆盖）。
- **外国公司**：20-F／40-F 的 XBRL 只有年报（IFRS），季度数字在 6-K 新闻稿里，要人工录入；SK 海力士在 SEC 只有 F-1 和 6-K。
- **多类股份**：XBRL 接口不给封面的合计股数，脚本退回到资产负债表日的已发行股数（须对照原文）；都没有的从原文封面录入。
- **www.sec.gov 不接受未声明联系方式的命令行请求**（403，“Undeclared Automated Tool”）。没有为此伪造联系方式，命令行只用 `data.sec.gov` 接口；文件原文用网页读取工具打开。
- 估值倍数用的是 GAAP 数字（不是公司的“调整后”口径）；企业价值不含少数股东权益、优先股、租赁负债和权益投资，各家页面上写明。

## 数据放在哪

`data/fundamentals/<代码小写>.json`，一个标的一个文件，格式见 `docs/DATA_MODEL.md` 的“估值相关信息”一节。没有文件的标的，详情页照常显示，只多一行“本轮未检索到”。
